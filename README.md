# 과제 발표 투표

QR로 접속해 후보 13명 중 한 명에게 한 표를 주는 투표 페이지입니다. 각 후보의 과제명을 카드로 보여 주고, 발표 화면에서는 실시간 막대그래프로 결과를 보여 줍니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (수정할 필요 없음) |
| `data/candidates.js` | **후보 명단 — 이 파일만 수정** (`[성명, 소속, 과제명]`) |
| `apps-script/Code.gs` | 구글 시트에 투표를 저장하는 코드 |

## 화면

- **참가자 화면:** 기본 주소. 카드를 눌러 고르고 확인하면 투표 끝. 같은 기기는 한 번만 투표됩니다.
- **결과 화면:** 주소 뒤에 `?result`. QR·참여 인원·후보별 막대그래프. 처음엔 득표를 가려 두고 **결과 공개하기**를 누르면 순위대로 정렬됩니다. 5초마다 자동 갱신.
- **미리보기:** `?result&demo` — 가짜 득표로 결과 화면 모양 확인.

## 새 투표 시작

`data/candidates.js`의 `voteId`를 바꾸고, 구글 시트 "투표" 탭의 2행부터 지웁니다.

## 한계

한 표 제한은 기기(브라우저) 기준입니다. 브라우저 기록을 지우거나 다른 브라우저를 쓰면 다시 투표할 수 있습니다.
