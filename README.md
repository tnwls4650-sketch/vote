# 인사팀 AI 활용 우수작 선정 (투표)

QR로 접속해 후보 중 한 명에게 한 표를 주는 투표 페이지입니다. 캐릭터 'AI 대리'(회사원)가 시상식 진행을 맡습니다. 결과 발표는 진행자가 [다음]·Space·→·PageDown으로 한 단계씩 넘기고, 득표 막대에서 상위 3위는 표 수를 가립니다.

## 화면 세 개 (주소 하나)

| 주소 | 화면 |
|---|---|
| `…/vote/` | **참가자** — 후보 카드(이름·소속·과제명)에서 한 명을 골라 투표. 기기당 한 표 |
| `…/vote/?result` | **발표 화면(빔)** — QR → 투표 시작 → 투표중 → "○초 뒤에 투표가 완료됩니다" → 완료 → 결과 발표(두구두구 → 막대 → 득표자 룰렛 → 최종 1위와 과제) |
| `…/vote/?admin` | **관리자** — 후보 명단·제목·투표 시간 입력, 투표 초기화 |
| `…/vote/?result&demo` | 저장소를 건드리지 않고 발표 연출만 미리보기 |

관리자·발표 화면 PIN은 `apps-script/Code.gs`의 `ADMIN_PIN`입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전부 |
| `data/candidates.js` | 저장소 주소(`voteUrl`)와 QR 주소(`qrUrl`) |
| `apps-script/Code.gs` | 구글 시트 저장소 코드 (시트 "과제 발표 투표 저장소"에 배포됨) |

명단은 파일이 아니라 **관리자 화면**에서 넣습니다. 엑셀에서 성명·소속·과제명 세 칸을 복사해 한 번에 붙여넣을 수 있습니다.

## 저장소 코드를 고쳤을 때

Apps Script 편집기 → [배포] → [배포 관리] → 연필 → 버전 "새 버전" → 배포. 주소는 그대로 유지됩니다.

## 한계

한 표 제한은 기기(브라우저) 기준입니다. 브라우저 기록을 지우거나 다른 브라우저를 쓰면 다시 투표할 수 있습니다.
